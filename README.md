### About

I'm a full-stack developer at **Izoc Solution**, building and shipping web applications end to end — React, Next.js and **Remix** dashboards on the client, Node.js and Python/FastAPI on the server.

The work has moved steadily toward **forward deployed engineering**: sitting with the problem in a real customer's environment, then designing the system that actually fits it — retrieval pipelines, models trained and fine-tuned on their data, agentic workflows, and the automations that keep all of it running after I leave.

I care about the parts that make software hold up: clear data models, dependable APIs, and interfaces that stay out of the way.

- **Role** — Full Stack Developer at Izoc Solution
- **Focus** — Forward Deployed Engineer: AI systems shipped and operated in production
- **Working on** — RAG pipelines, model training and fine-tuning, agents and automations
- **Based in** — Pakistan (PKT, UTC+5)
